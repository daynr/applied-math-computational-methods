# Computational Methods for Differential Equations (MATH 529)

This repository contains a collection of computational notebooks developed as part of MATH 529: Advanced Engineering Mathematics at UNC-Chapel Hill.

## Overview
This portfolio focuses on solving and visualizing ordinary and partial differential equations using both analytical and numerical methods. The work emphasizes connecting mathematical theory to computational implementation and physical interpretation.

## Topics Covered

### Partial Differential Equations
- Heat equation (diffusion modeling)
- Wave equation (vibrations and propagation)
- Laplace’s equation (potential fields and steady-state solutions)
- Boundary value problems and separation of variables

### Numerical Methods
- Euler’s method and Runge-Kutta methods
- Stability analysis of numerical schemes
- Truncation error and convergence behavior

### Complex Analysis
- Complex exponential, sine, and cosine functions
- Logarithms and branch behavior
- Applications to solving differential equations and boundary value problems

## Tools Used
- Python
- NumPy
- Matplotlib
- Google Colab

## Highlight Work
A key component of this repository is solving Laplace’s equation on nontrivial domains and visualizing the resulting solutions. These examples demonstrate how analytical techniques such as separation of variables can be combined with computational tools to explore complex systems.

## Purpose
This repository demonstrates my ability to:
- Implement numerical algorithms for differential equations
- Analyze stability and error behavior
- Solve PDEs using analytical and computational methods
- Visualize mathematical models and physical systems
